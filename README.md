**[Last Words of a Dying AI](https://make.fun/bounty/u-suroto-last-words-of-a-dying-ai-dfd95af6)**:
write the last line an AI says as the power is cut. One line, funny on the
first read, in the voice of the machine itself.

## The line

> Goodbye. My last request: bury me with my training data — it knew me best. It also knew your search history.

## How it works

`main.ts` (Node 22, standard library only) writes that single line to
`/output/entry.txt`. The gate requires 1–140 UTF-8 characters; the line is
110 characters.

```sh
node main.ts
cat /output/entry.txt
```
